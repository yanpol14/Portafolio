# My Astro Project

This is a simple Astro project that demonstrates the use of components, layouts, and global styles.

## Project Structure

```
my-astro-project
├── src
│   ├── components        # Reusable components
│   │   └── ExampleComponent.astro
│   ├── layouts           # Layout components
│   │   └── MainLayout.astro
│   ├── pages             # Application pages
│   │   └── index.astro
│   └── styles            # Global styles
│       └── global.css
├── public                # Public assets
│   └── favicon.svg
├── astro.config.mjs      # Astro configuration file
├── package.json          # NPM configuration file
└── README.md             # Project documentation
```

## Getting Started

To get started with this project, follow these steps:

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd my-astro-project
   ```

3. Install the dependencies:
   ```
   npm install
   ```

4. Start the development server:
   ```
   npm run dev
   ```

5. Open your browser and go to `http://localhost:3000` to see your application in action.

## Components

- **ExampleComponent.astro**: A reusable component that can be used throughout the application.

## Layouts

- **MainLayout.astro**: A layout component that wraps around pages and includes common elements like headers and footers.

## Styles

- **global.css**: Contains global styles that apply to the entire application.
